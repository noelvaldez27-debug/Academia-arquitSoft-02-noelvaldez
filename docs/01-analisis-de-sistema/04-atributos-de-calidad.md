# Atributos de calidad


| ID | Atributo de calidad | Escenario de calidad |
| --- | --- | --- |
| AC01 | **Rendimiento** | El postulante debe ver su nota individual en pocos segundos tras enviar su examen, aunque el ranking general del simulacro tarde algunos minutos en procesarse. |
| AC02 | **Disponibilidad** | El sistema debe permanecer disponible casi al 100% durante las horas críticas de cada simulacro o examen oficial, para las tres sedes. |
| AC03 | **Escalabilidad** | El sistema debe soportar 5,000 conexiones simultáneas en un simulacro masivo y crecer en número de sedes y matrícula sin requerir un rediseño mayor. |
| AC04 | **Seguridad** | Los datos personales y académicos de los postulantes deben estar protegidos mediante cifrado y control de acceso por rol (postulante, docente y administrador). |
| AC05 | **Mantenibilidad** | El sistema debe permitir incorporar nuevas sedes o módulos sin afectar los ya existentes. |
| AC06 | **Usabilidad** | La interfaz de resultados, ranking, gráficos y recomendaciones debe ser sencilla y comprensible para personas poco familiarizadas con la tecnología. |
| AC07 | **Resiliencia ante conectividad intermitente** | Si se pierde la conexión durante el examen, las respuestas deben conservarse en el dispositivo y enviarse automáticamente al recuperar la conexión, sin pérdida de información. |
| AC08 | **Eficiencia de costos** | El sistema debe operar con infraestructura mínima en días regulares y escalar solo durante los picos de uso, reduciendo el costo de cómputo. |
