# Historias de usuario

| ID | Historia de usuario |
| --- | --- |
| HU01 | Como administrador, quiero registrar estudiantes con su nombre, DNI, sede y carrera, para contar con un padrón centralizado de la academia. |
| HU02 | Como administrador, quiero que el sistema genere automáticamente las credenciales de cada postulante, para que puedan ingresar sin gestionar su propio registro. |
| HU03 | Como administrador, quiero cargar y editar el banco de preguntas por curso, para preparar los simulacros y exámenes de control. |
| HU04 | Como postulante, quiero rendir mi simulacro de forma virtual, para no depender del examen en papel. |
| HU05 | Como postulante presencial, quiero registrar mis respuestas desde mi celular, para rendir el examen impreso sin saturar la red de la sede. |
| HU06 | Como postulante, quiero conocer mi nota de forma inmediata al terminar el examen, para no esperar hasta el lunes siguiente. |
| HU07 | Como postulante, quiero ver mi ranking general, para conocer mi posición frente a los demás postulantes. |
| HU08 | Como postulante, quiero ver mi desempeño por curso y mi evolución a lo largo del tiempo, para identificar en qué cursos soy fuerte y en cuáles débil. |
| HU09 | Como postulante, quiero recibir una recomendación personalizada de refuerzo académico, para mejorar en los cursos donde cometo más errores. |
| HU10 | Como docente, quiero consultar las preguntas y temas con mayor tasa de error del grupo, para reforzarlos en clase. |
| HU11 | Como administrador, quiero emitir reportes de inscripción y participación y exportar los resultados, para apoyar las decisiones de la dirección académica. |
| HU12 | Como docente, quiero subir mis separatas en el formato que tenga (Word, PDF o imagen), para que el sistema genere preguntas a partir de ellas sin tener que escribirlas una por una. |
| HU13 | Como docente, quiero revisar, corregir y aprobar las preguntas que propone la inteligencia artificial, para que solo entren al banco de preguntas las que yo valido. |
| HU14 | Como administrador general, quiero registrar docentes con credenciales generadas automáticamente, para que puedan ingresar al sistema a subir separatas y consultar reportes sin necesidad de autoregistro. |
| HU15 | Como administrador, quiero registrar a muchos estudiantes de una sola vez subiendo un archivo Excel con su nombre, DNI, sede y carrera, para no tener que registrarlos de uno en uno. |
| HU16 | Como administrador de sede, quiero ver y gestionar solo a los estudiantes de mi sede, para trabajar únicamente con mi grupo y no modificar los de otras sedes. |
| HU17 | Como administrador, quiero consultar la lista de usuarios del sistema, para saber quién tiene acceso y con qué rol. |
| HU18 | Como administrador, quiero desactivar y reactivar usuarios sin borrarlos, para quitarles el acceso conservando su historial de exámenes y resultados. |
| HU19 | Como administrador general, quiero crear las cuentas de los administradores de cada sede, para delegar en ellos el registro de los estudiantes de su sede. |
| HU20 | Como usuario del sistema, quiero iniciar sesión con mi correo y contraseña, para acceder solo a las funciones que corresponden a mi rol. |
| HU21 | Como usuario del sistema, quiero cambiar mi propia contraseña cuando lo desee, para proteger mi cuenta. |
| HU22 | Como administrador, quiero cambiar mi propio correo, para mantener actualizados mis datos de acceso. |
