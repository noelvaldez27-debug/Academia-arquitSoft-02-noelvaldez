# Historias de usuario


| ID | Historia de usuario |
| --- | --- |
| HU01 | Como administrador, quiero registrar estudiantes, para contar con un padrón centralizado de la academia. |
| HU02 | Como administrador, quiero que el sistema genere automáticamente las credenciales de cada postulante, para que puedan ingresar sin gestionar su propio registro. |
| HU03 | Como administrador, quiero cargar y editar el banco de preguntas por curso, para preparar los simulacros y exámenes de control. |
| HU04 | Como postulante, quiero rendir mi simulacro de forma virtual, para no depender del examen en papel. |
| HU05 | Como postulante presencial, quiero registrar mis respuestas desde mi celular, para rendir el examen impreso sin saturar la red de la sede. |
| HU06 | Como postulante, quiero conocer mi nota de forma inmediata al terminar el examen, para no esperar hasta el lunes siguiente. |
| HU07 | Como postulante, quiero ver mi ranking general, para conocer mi posición frente a los demás postulantes. |
| HU08 | Como postulante, quiero ver mi desempeño por curso y mi evolución a lo largo del tiempo, para identificar en qué cursos soy fuerte y en cuáles débil. |
| HU09 | Como postulante, quiero recibir una recomendación personalizada de refuerzo académico, para mejorar en los cursos donde cometo más errores. |
| HU10 | Como docente, quiero consultar las preguntas y temas con mayor tasa de error del grupo, para reforzarlos en clase. |
| HU11 | Como administrador, quiero emitir reportes de inscripción y participación y exportar los resultados, para apoyar las decisiones de la dirección académica. |
